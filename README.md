# game-backlog

This is a repo that contains the tutorial code

Here you can see a Python/Flask + MongoDB application

## .env setup

```env
MONGO_URI="<you URI/Conn string>"
DB_NAME="<your DB NAME>"

SECRET_KEY=<your output from `python -c "import secrets; print(secrets.token_hex(32))"`>
```
